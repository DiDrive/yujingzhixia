# 局内出生与撤离系统设计

## 目标

形成当前样机的最小局内闭环：

```text
进入地图 → 出生点放置玩家 → 搜索与拾取 → 进入撤离点 → 倒计时 → 撤离成功
```

## 编辑器对象

### 玩家出生点

- 层级位置：`MapMarkers/PlayerSpawnPoints`
- 组件：`MapSpawnPoint`
- 场景中不预摆 Player；`GameBootstrap` 从配置的 Player Prefab 实例化玩家。
- `Spawn Id`：点位唯一 ID。
- `Spawn Kind`：玩家点必须选择 `Player`。
- `Radius`：为 `0` 时精确出生；大于 `0` 时在圆形范围内随机。
- `StartScene` 默认点：`PlayerSpawn_Default`，ID 为 `player_default`。

### 撤离点

- 层级位置：`MapMarkers/ExtractionPoints`
- 组件：`ExtractionPoint`
- 不依赖碰撞器，直接按照玩家与点位之间的世界坐标距离判断。
- `Radius`：撤离触发范围。
- `Countdown Duration`：必须持续停留的秒数。
- `Available`：是否启用该撤离点。
- `StartScene` 默认点：`Extraction_Default`。

### 撤离 UI

- 复用场景 Canvas 下的 `WorldInteractionPromptUI`。
- UI 节点全部预先存在于编辑器中；运行时只修改文字、显隐和填充比例。
- 进入撤离范围后，撤离倒计时优先于普通搜索提示。

## 运行规则

1. `GameBootstrap` 在地图启动后选择 `Player` 类型出生点，并从 Player Prefab 生成玩家。
2. `Preferred Player Spawn Id` 有值时优先选择匹配点位；否则随机选择。
3. 玩家进入可用撤离点半径后自动开始倒计时，不需要按键。
4. 玩家离开范围后立即取消，进度归零。
5. 多个撤离点并存时，同一时刻只有一个点占用公共倒计时 UI。
6. 倒计时结束后发布 `ExtractionCompletedEvent`，保留当前玩家背包，并切换到庇护所阶段。
7. 撤离成功后立即关闭玩家移动、攻击、武器切换和世界交互输入。
8. 当前项目尚无独立庇护所场景，所以暂不执行场景加载；正式场景和存档系统接入后订阅撤离完成事件。

## 本局状态

- 普通场景重载不会清空搜索容器会话快照。
- 只有明确调用“开始新一局”入口时，才根据 `GameBootstrap` 配置清空上一局容器状态。
- 撤离成功本身不立即删除背包和容器数据，避免在正式结算保存前丢失战利品。

## 验收

- 开始运行后玩家出现在配置的出生点。
- 编辑状态下场景无需存在 Player 实例，运行时只生成一个玩家。
- 进入撤离半径后出现倒计时 UI，填充与数字同步变化。
- 中途离开后 UI 消失，再次进入时从零开始。
- 倒计时结束显示撤离成功，且玩家背包内容不变。
- 撤离成功后 WASD、攻击和搜索输入均不可继续控制角色。
- 多个撤离点不会同时驱动同一个进度条。
