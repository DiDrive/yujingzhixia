# 基地场景与跨场景流程设计

## 当前目标

第一阶段先建立可运行的双场景主循环：玩家从基地整理物资并出击，再从局内地图撤离返回基地。基地目前是可编辑灰盒，后续直接替换场景美术和 UI 图片，不需要重写流程。

## 场景职责

### PersistentGameCore（跨场景核心）

- 核心预制体位于 `Assets/Prefabs/Core/PersistentGameCore.prefab`。
- 基地和局内地图都在编辑器内预摆同一个核心预制体，因此任意一张场景都可以直接运行调试。
- 首个初始化的核心成为本次游戏会话的数据源，并通过 `DontDestroyOnLoad` 跨场景保留。
- 新场景自带的核心仅用于独立运行兜底；发现已有权威实例后会自动销毁，不会出现两套背包或生存数据。

### StartScene（局内地图）

- 地图、敌人、搜索容器、露天物资、撤离点。
- 局内玩家、主相机、小地图与局内 UI。
- `GameBootstrap` 负责本局初始化、出生和撤离完成处理。

### ShelterScene（基地）

- 基地地形、墙体和功能模块位置。
- `ShelterSpawn_Return` 返回出生点。
- 仓库、工作台、饮水台、休息区和出击点。
- 基地玩家、基地相机、主背包/仓库 UI 与人物状态 HUD。
- 所有灰盒对象、碰撞器和 UI 都保存在场景中，可在编辑器直接修改。

## 跨场景保留与重建

跨场景保留的是数据服务，不是玩家和 UI：

- `GameStateMachine`
- `SurvivalSystem`
- `InventoryService`
- `GridInventoryService`
- `LootTableDatabase`
- `WorkbenchService`
- `ShelterModuleService`
- `NightAssaultSystem`

场景切换时重新创建的是：

- Player GameObject
- Camera
- Canvas 与各场景 UI
- 地图、敌人、搜索容器和功能点

这样可以避免把上一张地图的碰撞器、相机引用或 UI 引用带进下一张场景，同时确保玩家背包和生存值不丢失。

## 物品容器边界

- `Player` 容器：主背包和口袋，属于玩家随身物品，可被消耗品和制作系统读取。
- `Storage` 容器：基地永久仓库，当前 ID 为 `shelter_stash`，不计入随身物品统计。
- `WorldLoot` / `Corpse`：本局地图临时容器，开始新一局时统一清理。

成功撤离后，玩家已经拾取到背包里的物资继续留在 Player 容器。没有拾取的世界容器内容不会转入基地仓库。

## 运行流程

1. 游戏默认加载 `ShelterScene`，状态进入 `Shelter`，玩家在基地出生。
2. 玩家可用 F 键操作仓库、饮水、休息、工作台和出击点。
3. 使用出击点后清理上一局 WorldLoot/Corpse 状态，加载 `StartScene`。
4. 局内 UI 绑定常驻数据，状态进入 `Breakout → Raid`，玩家在地图出生点生成。
5. 撤离点倒计时完成，冻结玩家输入并显示撤离成功提示。
6. `SceneFlowController` 返回 `ShelterScene`；背包、生存值和基地状态继续使用同一份常驻数据。

## 编辑器调整位置

- 基地场景：[ShelterScene.unity](../Scenes/ShelterScene.unity)
- 功能区：`Shelter_Stations/Station_*`
- 交互范围：每个功能区上的 `BoxCollider2D` 大小。
- 功能和提示名：`ShelterInteractionPoint` Inspector。
- 返回出生点：`ShelterSpawn_Return`。
- 主背包与基地仓库：`Canvas/InventoryUI_main_bag`、`Canvas/InventoryUI_shelter_stash`。
- 口袋 UI：`Canvas/InventoryUI_min_bag`，引用 `Assets/Prefabs/Bag/InventoryUI_min_bag.prefab`，与局内共用同一布局。
- 仓库 UI：引用独立的 `Assets/Prefabs/Bag/InventoryUI_shelter_stash.prefab`；位置、格子尺寸、间距和背景都在该预制体中调整。
- 仓库行列数：`Shelter_SceneController/ShelterSceneController` 的 `Stash Rows`、`Stash Columns`；背景会按实际行列数自动适应。
- 修改仓库行列数后，执行 `Tools/余烬之下/基地系统/同步仓库预制体的行列预览`，会重建 Prefab 内真实的 `Cell_*` 节点，使编辑器预览与运行时配置一致。
- 世界交互提示：`Canvas/WorldInteractionPromptUI`。
- 人物状态：`Canvas/PlayerHUD`。

如需重建灰盒，可使用 `Tools/余烬之下/基地系统/重新构建基地灰盒场景`。该操作会覆盖 `ShelterScene`，正式开始手工搭建基地后不要再执行重建。
只同步核心预制体而不覆盖基地内容时，使用 `Tools/余烬之下/基地系统/同步跨场景核心`。
