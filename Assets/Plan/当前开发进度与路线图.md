## 已完成

- 网格背包基础数据模型、占格、旋转、堆叠与移动。
- 主背包与世界物资容器共用网格 UI。
- 容器行列数和单格尺寸自适应。
- 露天物品拾取进入玩家背包。
- 独立 `SearchableLootContainer + Collider2D` 地图搜索点。
- 容器首次搜索、JSON 掉落表生成和再次开关。
- 容器内物品按格子顺序和品质耗时逐件揭示。
- 未揭示物品禁止拖拽、旋转、拆分和丢弃。
- 编辑器中可调整的容器 UI 与世界交互提示 UI。
- 世界交互视线阻挡：距离足够但隔墙时不可搜索或拾取，搜索中被墙体隔断会立即取消。
- 玩家出生点选择和地图启动定位。
- 撤离点范围、自动倒计时、离开取消和撤离成功事件。
- 撤离倒计时复用编辑器中已有的世界交互提示 UI。
- 生存属性改为连续流逝，并只在配置的局内阶段推进。
- 生命值增加独立上限，旧场景中的异常 `hp = 500` 已迁移为 `100 / 100`。
- 饥饿、口渴和疲劳惩罚已接入玩家移动、伤害与蓄力攻击。
- 新增编辑器可见、可调整的人物生存 HUD 构建工具。
- 搜索容器、夜袭奖励和调试发放已统一使用 `loot_tables.json`。
- `InventoryService` 已精简为 `GridInventoryService` 的统一适配入口，不再保存第二份旧式 Stacks。
- 搜索容器和露天物资增加逻辑楼层编号，不同于玩家当前 `ActiveFloorIndex` 时不显示提示也不能交互。
- 背包增加编辑器可见的“使用”按钮和使用进度条。
- 消耗品效果、使用时间及副作用改由 `item_definitions.json` 配置。
- 使用完成后精确扣除当前选中的物品堆叠，并立即更新生命、饥饿、口渴、疲劳或感染状态。

## 当前任务

### SEARCH-01：配置归一

状态：已完成（2026-07-23）

- Player 已挂载 `PlayerInteractor2D` 时，以该组件 Inspector 参数为唯一来源。
- `GameBootstrap` 只给运行时新创建的交互器写默认值。
- 验收：Player 的 `Interaction Range = 0.8`，进入运行模式后仍保持 `0.8`。

### SEARCH-02：容器状态快照

状态：会话级基础已完成（2026-07-23）；正式磁盘存档待总存档系统接入。

- 以 `persistentId` 作为容器稳定键。
- 保存是否生成、是否完成首次搜索、剩余物品布局及逐物品揭示状态。
- 场景卸载/重新加载时不得重新抽取掉落。
- 当前先实现会话级仓库，不写入 `PlayerPrefs`。
- 后续总存档系统接入时，复用相同数据契约写入正式存档槽。

### SEARCH-03：稳定性验证

状态：待 Unity Play Mode 人工回归。

- 多个容器相邻时始终选择有效的最近目标。
- 搜索中离开范围或松开按键时进度正确重置。
- 背包已满时物品不丢失，并显示失败反馈。
- 容器关闭再打开时继续保持揭示状态。
- 场景重载后剩余物品和已揭示状态一致。

### SURVIVAL-01：生存属性闭环

状态：基础实现已完成（2026-07-24）；待 Unity Play Mode 人工回归。

- 饥饿、口渴、疲劳按“每分钟衰减值”连续变化，HUD 不再长时间静止后突然跳变。
- 庇护所和结算阶段默认暂停自然流逝，突围、搜刮与可选夜袭阶段继续流逝。
- 生命、饥饿、口渴、疲劳分别拥有当前值和上限。
- 口渴过低降低移动速度；饥饿过低降低近战与远程伤害；疲劳危险时禁止蓄力攻击。
- 感染、极度饥饿和极度缺水造成的生命损失改为连续计算。

### HUD-01：人物生存 HUD

状态：脚本与编辑器构建工具已完成（2026-07-24）；待确认视觉样式。

- HUD 包含生命、饥饿、口渴、精力和感染状态。
- `PlayerHUD` 是主 Canvas 下的普通编辑器对象，运行时只刷新，不创建 UI。
- 非运行状态可使用预览值调整填充条、文字、位置、大小与颜色。
- 如场景中未自动出现，可使用 `Tools/余烬之下/人物 HUD/创建人物生存 HUD` 创建。

### CONSUMABLE-01：背包消耗品

状态：基础实现已完成（2026-07-27）；待 Unity Play Mode 人工回归与扩充物品数值。

- `GridItemDefinition` 新增 `usable`、`useDuration` 和 `useEffects`。
- 支持 `Health`、`Hunger`、`Thirst`、`Fatigue`、`CureInfection` 与 `Infection` 效果。
- 状态已满且没有任何有效收益时不会扣除物品。
- 使用期间显示百分比进度；完成后从当前选中实例精确扣除一个。
- 已在同一 JSON 中建立 11 个可复用使用档案，共配置 72 种食品、饮料和医疗物品；材料、工具、清洁用品与生食原料保持不可直接使用。

- `StartScene` 当前玩家实例已开启视线检查；目标选择和按住交互期间都会持续验证。

- 普通场景重载不会清空本局容器快照。
- `ExtractionPoint` 支持进入范围自动倒计时、离开取消、多撤离点互斥和成功事件。
- 撤离成功后立即冻结玩家移动、攻击、武器切换和世界交互输入。
- 当前项目没有独立庇护所场景，撤离成功暂时保留背包并切换到庇护所阶段。
- `SurvivalSystem` 从间隔跳扣迁移为每分钟连续流逝，并增加各属性上限与局内阶段开关。
- `PlayerCombatController2D` 已应用生存系统的移动、伤害和蓄力限制。
- 新增 `PlayerSurvivalHUD` 以及只在编辑器中创建场景 UI 的构建工具。
- 主运行程序集与编辑器程序集编译检查均为 0 错误。
- 旧 `Gameplay_LootSpawner` 场景配置已迁移为 `Core_LootTableDatabase`。
- `loot_tables.json` 新增 `night_assault_reward`，夜袭奖励不再读取 Inspector Entries。
- 调试物资发放改用 `survival_basic`；掉落事件以 `tableId` 标识来源。
- `Core_Inventory` 已直接绑定场景中的 `GridInventoryService`，旧 `Max Slots`、`Default Stack Limit` 和 `Stacks` 数据已移除。

- 世界交互增加逻辑楼层硬限制，换楼时中断搜索并关闭已打开的隔层容器。
