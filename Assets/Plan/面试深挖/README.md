# 《余烬之下》Unity 面试深挖教材

原《Unity 面试项目手册》定位为速查、背诵和题库。本目录定位为原理教材：不要求一分钟读完，而要求每个主题能回答“为什么、内部怎样运行、哪里会出错、项目如何证明、换一种方案行不行”。

## 固定答题结构

每个主题尽量覆盖八层：

1. 问题本质：面试官真正考什么。
2. 基本定义：把术语说准确。
3. 运行机制：数据如何流动、对象如何协作。
4. 项目证据：对应到真实类型和方法。
5. 设计理由：为什么采用当前方案。
6. 边界与缺陷：什么时候会失败。
7. 商业化演进：规模扩大后如何改。
8. 连续追问：面试官还能怎样往下问。

## 使用方式

先遮住答案，用 30 秒给结论，再用 3 分钟展开机制，最后回答连续追问。不会的内容回到对应代码验证，禁止只记模式名称或结论句。
